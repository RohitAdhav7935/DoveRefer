# 🕊️ DoveRefer — LinkedIn Referral Message Generator

### Your Message. Your Connection. Your Opportunity.

DoveRefer is a simple web application that helps job seekers generate personalized LinkedIn referral request messages in seconds.

Whether you're a fresher looking for your first opportunity or an experienced professional exploring new roles, DoveRefer helps you write clear, professional referral requests.

🌐 **Live Website:** https://rohitadhav7935.github.io/DoveRefer/

---

## ✨ Features

- 📝 **Three Message Formats:** Generate Short, Medium, and Long referral messages.
- 🎓 **Fresher Mode:** Create messages suitable for entry-level candidates.
- 💼 **Experienced Mode:** Personalize messages using years of professional experience.
- 🎯 **Personalization:** Include employee name, company name, job position, and requisition ID.
- 📋 **Copy Messages:** Copy generated messages with one click.
- 📱 **Responsive Design:** Use the application on desktop and mobile devices.
- 🔒 **Browser-Based Processing:** Messages can be generated directly in the browser without an external AI API.

## 🚀 How to Use

1. Open the DoveRefer website.
2. Enter the employee's name and company name.
3. Enter the job position and requisition ID, if available.
4. Select Fresher or Experienced.
5. If Experienced is selected, enter your years of experience.
6. Add your relevant skills.
7. Generate Short, Medium, or Long referral messages.
8. Copy your preferred message.
9. Review it and send it through LinkedIn.
